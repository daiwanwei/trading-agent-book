## Global Constraints

- 語言：繁體中文敘事；術語、指令、檔名、artifact 名稱保留英文 backticks。
- 上游 repo（READ-ONLY）：本機 `~/Projects/wade/math/claude-trading-skills`；連結格式 `https://github.com/tradermonty/claude-trading-skills/blob/main/<path>`（或 `/tree/main/`）。
- 場景不虛構：敘事只用 `workflows/*.yaml` 真實 step / `decision_gate` / artifact 名稱。
- 重述不搬運：不整段翻譯上游文字；引用以繁中重述 + 連結。
- 五段章節模板（3.1–3.3）：場景 → 方法論 → 機制 → 判讀與誤用 → 延伸閱讀。3.4 與實作章結構見各該任務。
- 數字鐵則：章節中每個數值門檻/百分比/公式都必須能在列出的來源檔案中找到；來源不支持就不寫。
- **閘門語義鐵則（M1 定案，違反即 Critical）**：`prerequisite_workflows` 與各 gate 的「攔截」是寫給人看的紀律，不是程式強制——ch1.5 已釘死此語義（`book/part1-regime/05-exposure-posture.md`）。但注意分寸：斷路器與紀律閘門的 **script 本身確實會計算出 verdict**（如 `TRADING_ALLOWED`、GO/NO-GO），「不是程式強制」指的是沒有任何程式攔住你無視 verdict 下單。兩者都要寫準。
- 立場：姿態不是訊號、所有訂單由人手動下、非投資建議；實作章結尾重申。
- SUMMARY.md 的第三部標題已鎖定，不得改（`book/SUMMARY.md`）。每章 H1 必須與 SUMMARY 條目文字一致。
- 每章完成後：`python3 scripts/check_book.py` → `0 issue(s)`。
- 所有 commit 訊息結尾：`Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`。
