```python
CJK_RE = r"[\u3000-\u303f\u4e00-\u9fff]"
HALFWIDTH_NEAR_CJK_RE = re.compile(
    rf"(?:{CJK_RE}[,;:?!])|(?:[,;:?!]{CJK_RE})"
)
CODE_SPAN_RE = re.compile(r"`[^`]*`")
FENCE_RE = re.compile(r"^```.*?^```", re.M | re.S)
LINK_DEST_RE = re.compile(r"\]\([^)]*\)")


def find_halfwidth_punct(text: str) -> list:
    stripped = FENCE_RE.sub("", text)
    hits = []
    for lineno, line in enumerate(stripped.splitlines(), 1):
        clean = CODE_SPAN_RE.sub("", line)
        clean = LINK_DEST_RE.sub("]()", clean)
        m = HALFWIDTH_NEAR_CJK_RE.search(clean)
        if m:
            hits.append((lineno, m.group(0)))
    return hits
```

注意：FENCE 剝除會改變行號——實作時 fenced block 改為「逐行掃描 + 進出 fence 狀態機」以保留正確行號（上面的 sub 版本僅為概念；實作採狀態機版，測試以行號斷言把關）。`check_punctuation` 對 `book_dir.rglob("*.md")` 逐檔跑 `find_halfwidth_punct`，issue 格式 `"<相對路徑>:<行號>: halfwidth punct near CJK: <片段>"`。main() 開頭加 `if not (args.book / "SUMMARY.md").exists(): print(f"error: SUMMARY.md not found at {args.book}", file=sys.stderr); return 1`，並把 `check_punctuation` 的 issues 併入總回報。
